## Restricted operator workflow

Run these commands only from the full reviewed source checkout on the operator's private machine, with the isolated operator DSN and Django key loaded without printing or placing secrets in argv. Production hosted runtimes reject operator mode and do not contain these commands. No browser endpoint provides operator access.

```sh
.venv/bin/python manage.py waitlist_ops status --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops pause --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops export --output /private/operator/export-new.json --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops delete --email-file /private/operator/verified-address.txt --ledger /private/operator/erasures.jsonl --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops purge --ledger /private/operator/erasures.jsonl --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops reconcile --ledger /private/operator/erasures.jsonl --settings config.waitlist_settings
.venv/bin/python manage.py waitlist_ops resume --settings config.waitlist_settings
```

The paths above are schematic private paths, not an existing credential store. Parent directories must be owned by the operator and mode 0700; input/ledger/export files must be operator-owned regular files mode 0600. Deletion accepts an address only through a bounded private file after the operator verifies control of that address. It records an HMAC digest in the external fsynced ledger before deleting; raw addresses never enter argv or deletion receipts. All commands serialize database state changes; deletion/cleanup/reconciliation also lock the external ledger. Recovery reconciliation requires pause. Missing/corrupt ledgers and database failures stop the operation with a redacted error. A generic failure can follow a completed deletion/export, so inspect private state before retrying. JSON exports avoid spreadsheet formula evaluation; treat them as personal-data copies, never as a public download.

Maintain a private export inventory with file identity, creation time, owner, permitted use and expiration; update/delete each managed copy on a verified deletion/correction request and within the 90-day record lifetime. Never email an export, paste it into an issue, add it to an analytics tool or commit it. Do not promise deletion of uncontrolled copies; do not create such copies.
