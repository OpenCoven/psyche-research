## First failures and corrections

The initial new homepage regression failed because the archive homepage had no waitlist. Operator regressions failed because the command was absent. A route-denial test initially supplied an empty Django-client POST, which omits Content-Type; the fixture was corrected to send a bounded URL-encoded body, retaining the production 415 guard.

Native Safari initially showed no stylesheet because Django DEBUG=False runserver does not serve static assets; the owned loopback fixture alone used `runserver --insecure`. Safari then exposed an actual CSRF 403 under no-referrer; same-origin referrer policy preserved provenance and the same native workflow reached confirmation without weakening CSRF. The exact rejected Origin value was not captured and is not asserted.

Independent review reproduced private-value reflection in the default invalid-choice error, missing operator SELECT(expires_at) for cleanup, default-suite model discovery failure and permanently retained external erasure digests. Repairs add a generic error and regression, the narrow column grant plus actual restricted-role full-command tests, profile-isolated discovery plus dedicated CI commands, and locked atomic ledger compaction. A later review found that creating an absent recovery ledger before deletion could lose its directory entry on crash; deletion now requires a valid existing ledger, and durable initialization is an explicit operating step. The missing-ledger regression failed before repair and passed after it.

A monotonic clock-window regression failed before the rate hardening, then passed after calculating time under the state lock and refusing backwards counter resets. A bundle smoke test first selected the resolved Homebrew interpreter path instead of the venv path and failed to find Django; retaining the venv path fixed the test harness without changing the package.

The first full suite with offline packaging code failed the archive's reviewed runtime-import contract because `deploy/*.py` is part of that serving boundary. The preparer moved to `tools/`; the existing no-process import test was kept unchanged. All three focused static contracts and the successor full suite pass. First failed receipts are retained privately alongside successful successors.
