## Implementation and exact evidence limits

The implementation adds WorkOS-selected login/start/callback/logout, server-side expiring one-time PKCE attempts, explicit immutable-subject local identity links, encrypted server sessions, JWT/client/issuer checks, bounded refresh, an absolute local session maximum, safe provider errors and operator-only linking/revocation. Local password authentication remains available only when `AUTH_PROVIDER=local`; selecting WorkOS has no password fallback. Existing object ownership, explicit moderator groups, self-approval prevention and paused intake are unchanged. Recovery preserves bindings and clears all pending attempts and sessions.

Python 3.13.16, Django 5.2.19 and official WorkOS Python SDK 10.6.0 were used. The SDK and complete transitive dependency set are hash-pinned from actual PyPI release metadata, including Python 3.13 and ABI3 wheel hashes for the native dependencies. Registry access required child-process hostname resolution with normal TLS verification; machine DNS and certificate protections were not changed. The macOS trust-store call failed with OSStatus -26276, so pip used its verified certificate bundle instead. No `--trusted-host`, disabled verification or insecure credential storage was used.

A fresh isolated virtual environment installed the entire requirements file with `--require-hashes` successfully. `pip check` reported no broken requirements, and the fresh environment passed Django system checks. Its install log is retained at `var/workos-hash-install.log` in the isolated checkout. The original shared application's database and server were not migrated or reconfigured.

Raw setup receipts remain in the ignored `var/workos-setup` directory of the original checkout.

The harness was corrected to exercise actual browser form encoding; the product boundary was preserved. Log: `var/workos-auth-first.log`.

Log: `var/workos-auth-second.log`.
4. Third focused run: 14 tests passed in 1.656 seconds. Real RSA signatures were verified against a synthetic pinned JWKS test key; provider code exchange/refresh remained mocked. Log: `var/workos-auth-third.log`.
