# Synthetic rendered review bundle

Issue #8's human review needs inspectable images and measured color evidence in addition to the integrated reflow/keyboard contract. The browser-input-contract CI job now prepares a seven-day downloadable artifact containing screenshots, a local HTML gallery, a source/measurement report and an explanatory README. This is synthetic test evidence, not published research or a deployed preview. The actual job result and source metadata determine whether it passed; implementation alone does not establish execution or acceptance.

Run `node --test archive/tests/browser_review.test.mjs` and then `python archive/tests/run_browser_input_limits.py` on the pinned Python environment with Node 22+, installed Chromium, fontconfig and the documented Ubuntu review-font packages. Start with no existing `var/browser-review` directory: the owner refuses a stale bundle rather than overwriting or mixing executions. The runner clears inherited provider/database/hosting configuration, migrates a private temporary SQLite database and serves loopback with pilot approval off. Session configuration, database and raw server logs remain in temporary scratch and are never uploaded. `var`, tests and docs remain excluded from Vercel deployment bundles.

The fixed artifact allowlist includes only PNG images, report.json, index.html and README.md from var/browser-review. It excludes all other JSON, fixture configuration, cookies, databases and logs. Source metadata records exact Git SHA/tree, a dirty-state boolean and hashes of the stylesheet, harness, review module, runner and workflow. The gallery has no JavaScript, remote images or external dependencies. Browser page requests remain limited to the synthetic loopback origin and Chromium's sandbox remains enabled.

The native engine captures six pages at 1440, 390 and 320 CSS pixels: home, empty archive, policies, local login, workspace and editor. Each has a full-page image and a viewport image of the keyboard skip link. A final narrow editor image records keyboard focus on a rejected artifact field. The full form uses synthetic multilingual maximum-length values and an explicitly synthetic unbroken title; images never contain participant records. The original input/save/rejection/persisted-state assertions remain mandatory.

Computed sRGB foreground/background pairs are measured in the renderer. The calculator uses [WCAG 2.2 relative luminance](https://www.w3.org/TR/WCAG22/#dfn-relative-luminance) and alpha compositing over ancestor backgrounds; thresholds are not rounded into a pass. Normal text requires 4.5:1 and large text 3:1, using the size/weight boundary in [Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). Explicit text-field boundaries and measured focus outlines are checked at 3:1. Computed colors are used rather than antialiased screenshot samples. Reference checks include black/white, equal colors, the near-4.5 gray boundary, transparency and rejection of unsupported color inputs.

Hidden/ARIA-hidden and disabled elements are counted separately. Unsupported image backgrounds, opacity, filters, blend modes or color formats are reported as unmeasured and fail the automated gate rather than receiving an inferred pass. Native checkbox/radio appearance, all other component states, browser/OS color differences, clipping/overlap and meaning still need visual review. The calculator is a bounded diagnostic, not a general accessibility auditor or WCAG conformance claim. Contrast failures and screenshots are preserved even when the job fails.

Download the matching source artifact, extract it and open index.html locally. Inspect the full images, compare the measured color report, and record browser/source, date, reviewer, pass/fail findings and any accepted accommodation. Actual 200%/400% browser zoom, cross-browser/device behavior, screen-reader workflow and human operating acceptance remain separate unrun gates. No automated, agent or screenshot result adopts policies, opens intake, authorizes deployment or completes the full pilot.
